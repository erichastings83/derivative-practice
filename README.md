# Derivative Practice App

An interactive web application for practicing derivative calculus, featuring multiple game modes, instant mathematical feedback, and step-by-step solutions.

## Features

- **Rule Coverage**: Practice basic derivative rules, product rule, quotient rule, and chain rule.
- **Game Modes**:
  - *Practice Mode*: Untimed practice with immediate step-by-step breakdown.
  - *Time Attack / Survival*: Fast-paced challenge modes to test speed and accuracy.
- **Interactive Math**: Rendered with [KaTeX](https://katex.org/) and evaluated with [math.js](https://mathjs.org/).
- **XP & Level Progression**: Track your streak, personal high scores, and level progression locally.

## Deployment

This is a static web application configured for deployment on [Vercel](https://vercel.com).
